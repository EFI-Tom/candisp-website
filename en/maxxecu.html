CAN bus display for MaxxECU

CanDisp 52 shows live RPM, lambda, and other MaxxECU data. The display usually comes preconfigured for MaxxECU. If your unit is set up differently, you can apply the MaxxECU settings by loading the JSON preset below

Download the MaxxECU preset

Setup in three steps

  1. Connect CanDisp

    Connect CAN-H, CAN-L, and power as described in the CanDisp wiring guide. Match the CanDisp bit rate to the bus you are using. MaxxECU specifies 500 kbit/s for its default CAN output.

  2. Configure CAN output in MTune

    In CAN Protocols, set Generic CAN output protocol to MaxxECU Default 1.3. If your MaxxECU has multiple CAN buses, select the bus that CanDisp is connected to. The preset uses the standard IDs with a CAN ID OFFSET of 0.

    For applications with VAG DSG, MaxxECU recommends Default 1.2 because CAN ID 0x540 overlaps. RPM and lambda are also available with version 1.2. MaxxECU CAN output documentation

  3. Load the preset in CanDisp

    Connect to the CanDisp Wi-Fi network, open the web interface, and save a JSON backup of your current settings. Then use the settings import to load settings_MaxxECU.json. Select an included screen and check the RPM reading with the engine running and the vehicle stationary.

If readings are missing

In the default output, CAN ID 0x520 carries RPM, throttle position, manifold pressure, and lambda. If RPM is missing, check the CAN connection, bit rate, output protocol, and ID offset. Other readings depend on the sensors and settings in your MaxxECU.

If MaxxECU and CanDisp are the only devices on the bus, select Normal CAN mode on CanDisp so it can acknowledge received messages.

For custom CAN output, edit the signal definitions in the CanDisp web interface or import a matching DBC file.

From a Vespa project to CanDisp

CanDisp began with a modified Vespa running MaxxECU fuel injection. I needed a round display for its engine data. The current CanDisp 52 is designed for use in a protected vehicle interior.
