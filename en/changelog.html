Firmware 3.2.13

Major feature update with CanDisp Street Dyno, expanded screen layouts, extended CAN support, and more flexible settings and recovery options.

  • Up to six readings per display screen
    • New layouts for showing several readings at once
    • Flexible combinations of readings on each screen
    • Support for the existing single-value and multi-value layouts
  • Extended CAN frame support
    • Support for 29-bit extended CAN identifiers in addition to standard 11-bit identifiers
    • Set the extended ID option separately for each CAN signal
  • Added CanDisp Street Dyno
    • Record acceleration runs from engine RPM and optional vehicle speed
    • Recording starts when RPM crosses the start threshold from below and ends after a sustained drop followed by a short period of additional recording
    • The configured target RPM determines whether a run is marked as complete
    • Save complete runs and, when needed, incomplete runs
    • Record additional readings such as TPS, MAP, lambda, ignition timing, or temperatures
    • Analyse power and torque directly in the CanDisp web interface
    • Choose other recorded readings to display in an additional chart
    • Adjust the amount of smoothing used in the analysis
    • Add run comments and import or export saved Dyno runs
  • Expanded Dyno run management
    • Archive recorded runs
    • Protect important runs from accidental deletion
    • Create multiple vehicle profiles with individual vehicle and gearing data
    • Enter ambient data such as air pressure and air temperature for each analysis
  • Expanded settings export and import
    • Back up Dyno recorder settings and vehicle profiles together with the CanDisp configuration
    • Full support for larger configurations
  • Selective settings import
    • Choose which sections to import when loading a configuration
    • The import only applies to the selected sections
  • Expanded reset options
    • Reset settings, Dyno data, and caches independently
    • Option to perform a full factory reset
    • A full factory reset rebuilds the internal configuration and file storage
  • Redesigned web interface
    • Reorganized main menu
    • New sections for Street Dyno and the expanded management features
    • More consistent navigation and controls on phones and desktop computers
  • Expanded recovery system
    • Recovery mode now also shows its status directly on the CanDisp display
    • Independent options to install firmware, try a normal boot, or reset settings
    • Recovery mode runs independently of normal display, CAN, BLE, and configuration initialization
  • Improved NVS integrity checks
    • Checks the internal standard NVS when recovery starts
    • Automatically repairs and reinitializes damaged standard NVS structures when possible
    • Improved handling of damaged or incomplete configuration data
  • Smaller improvements to stability, memory management, the web interface, and configuration handling

Firmware 3.2.12

Feature and stability update with Saab Trionic 7 support, expanded DBC import, a recovery system, and improved navigation.

  • Added Saab Trionic 7 support
    • Direct diagnostic communication with Trionic 7 ECUs
    • Read the ECU symbol catalog and select internal T7 measurements
    • Assign T7 readings to CanDisp signal slots
    • Protect saved T7 configurations when the ECU software version differs
  • Expanded the number of configurable signals from 16 to 60
  • Reworked DBC import
    • Improved signal list and search
    • Filter supported and unsupported signals
    • Assign imported signals to any of the 60 CanDisp signal slots
    • Improved handling of larger DBC files
  • Added the recovery system
    • BootGuard detects repeated failed boot attempts
    • Standalone minimal recovery mode with its own Wi-Fi network
    • Reinstall firmware even when the main firmware fails to boot fully
    • Try a normal boot or reset settings directly from recovery mode
  • Improved firmware updates over Wi-Fi
    • More robust handling during uploads and restarts
    • Option to downgrade to an older firmware version
    • Improved LVGL handling during updates
  • Reworked the web interface
    • Clearer, more consistent layout
    • Collapsible settings sections
    • Search, filter, and expand or collapse controls for large configurations
    • Improved operation on phones
  • Improved Wi-Fi and captive portal behavior
    • Wi-Fi stays active while a client device is connected
    • Improved simultaneous use of Wi-Fi and BLE
    • The configuration interface can also be opened at http://candisp.local/
    • More reliable behavior on phones and desktop computers
  • Expanded navigation support
    • Support for OsmAnd through the CanDisp Navigation app
    • Continued support for Google Maps
    • Support for routes planned or imported in OsmAnd
  • Added Blitzer.de PRO alerts
    • Alerts can appear as a temporary overlay on CanDisp
    • Automatically returns to the previous screen when the alert ends
  • Improved Bluetooth reliability
    • Switched the BLE stack to NimBLE
    • Improved connection and reconnection logic
    • More stable simultaneous operation with Wi-Fi
  • Reworked ESP-NOW
    • More stable operation with the Wi-Fi stack continuously available
    • Updated transmission for configurations with up to 60 signals
  • Improved settings storage and import
    • More reliable handling of larger configurations
    • Improved saving and restoring of the expanded set of signals
    • Configuration files include T7 mappings
  • Updated touch brightness controls
    • Long-press the upper or lower part of the display to adjust brightness
    • Support for the existing external button controls
  • Standardized and improved internal LVGL thread safety
  • Improved reset and restart reliability
  • Added support for more CanDisp display variants based on the Waveshare 1.28-inch and Seeed 0.70-inch displays

Firmware 3.2.11

First public release for CanDisp TFT1.85TP.

  • Displays CAN bus data on up to 16 configurable screens
  • Web-based configuration through a built-in Wi-Fi access point
  • DBC import and manual CAN signal definitions
  • Google Maps turn-by-turn directions via BLE and the CanDisp Navigation app
  • Adjustable display brightness via touch, buttons, and the dimmer input
  • Adjustable brightness curve for variable dimming signals
  • Switchable 120-ohm split termination
  • Configurable CAN bus bit rate and CAN mode
  • Firmware updates through the web interface
